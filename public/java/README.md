# ecj.jar

Eclipse Compiler for Java (ECJ) 3.26.0, from Maven Central
(`org.eclipse.jdt:ecj:3.26.0`, SHA-1 `4837be609a3368a0f7e7cf0dc1bdbc7fe94993de`).
Licensed under the Eclipse Public License 2.0: https://www.eclipse.org/legal/epl-2.0/

It runs inside CheerpJ (Java 8 in the browser) to compile the code learners write.
Version 3.26 is the last one that runs on Java 8; newer versions need Java 11+
and fail under CheerpJ's Java 11 module image.
